BIKE STUFF — rebuilt website

1) Распакуйте архив.
2) Загрузите ВСЕ файлы и папку assets в корень GitHub-репозитория (не только index.html).
3) GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
4) Подождите публикации GitHub Pages и откройте ссылку.

Страницы: Главная, Каталог, Корзина, Отзывы, Доставки, Заказ и доставка, О компании, Контакты.
Функции: поиск, фильтры, карточка товара, увеличение изображения, корзина с localStorage, форма заявки с переходом в Telegram.
Внимание:
- У ряда моделей пока нет подтверждённой фотографии — это прямо отмечено в карточке.
- Некоторые внешние изображения могут быть недоступны из-за ограничений стороннего сайта. Для коммерческой публикации лучше заменить их на фото, предоставленные поставщиком/правообладателем.
- Цены и наличие не выдумываются: отображается «Уточнить цену».
- Онлайн-оплата, серверная база и админ-панель не подключены.
- Сообщение в Telegram не отправляется автоматически: пользователь проверяет и отправляет его сам.
